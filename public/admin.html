Suspicious IPs

IPs that ran an unusually large number of distinct wallets through the Checker. The idea: a lazy Sybil-farm operator checking whether their own wallets got flagged would tend to do exactly this from one machine. It's a heuristic, not proof — shared IPs (offices, VPNs, mobile carrier-grade NAT) can trigger false positives just as easily. Raw IP addresses are never stored; only a salted hash is kept, so this page can never show you an actual IP.
