SYBIL SCANNER for Nado
Unofficial community tool — not affiliated with or endorsed by Nado. Cluster flags are statistical heuristics, not proof of wrongdoing. Verify anything important yourself.

Clusters

Live scan of recent protocol activity for three Sybil patterns: wallets funded with near-identical amounts minutes apart, wallets that mirror each other's long/short trades, and wallets that all trace back to the same funding source. Scans are windowed and bounded — widen the window for a deeper (slower) scan.

① Funding pattern — same-amount deposits, ≤5% off, within 10 minutes

Run a scan to see results.

② Mirror trading — opposite long/short, ≤5% size diff, within 15 seconds, open + close, ≥10 matched trades

Run a scan to see results.

③ Common funding source — one wallet first-funded more than N Nado depositors

Finds the first-ever funder of each depositing wallet (the classic "who bankrolled this fresh wallet" signal) and flags any funder that fed more than the threshold below. Known exchange / bridge wallets are excluded — see lib/exchangeWallets.js and the EXCLUDED_FUNDERS env var if a legitimate wallet shows up here anyway. This scan is the slowest of the three (one to two Ink Explorer lookups per depositor), so expect "(partial)" more often on wide windows.

Run a scan to see results.

Funding-pattern and common-funding-source data: Ink Explorer (on-chain deposits to Nado's Clearinghouse contract, and each depositor's own inbound transfer history). Mirror-trading data: Nado Archive API (off-chain trade tape — individual trades never touch the chain, so the block explorer alone can't see them).
